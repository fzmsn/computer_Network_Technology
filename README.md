# HCIA-Datacom V2.0 学习资料

本仓库用于整理和分享 **华为 HCIA-Datacom V2.0（数通方向）**
的学习资料，包含培训教材与配套实验内容，方便学习者查阅知识点、练习设备配置，并记录学习过程。

## 📚 资料内容

### 1. 培训教材

-   HCIA-Datacom V2.0 培训教材
-   数通网络基础知识
-   网络设备及其基本功能
-   数据通信原理与网络工程相关知识
-   各技术知识点、配置示例及课后思考内容

### 2. 实验资料

仓库同时整理了与课程学习配套的实验资料，可结合教材中的知识点进行练习。

建议按照以下流程学习：

1.  先阅读对应章节，理解基本概念和工作原理。
2.  根据实验说明准备网络设备或模拟实验环境。
3.  按照实验要求完成拓扑搭建与设备配置。
4.  使用相关命令检查配置结果，验证网络连通性及协议状态。
5.  整理实验过程、遇到的问题和解决方法。

## 🎯 学习目标

通过教材阅读和实验练习，逐步掌握：

-   数据通信网络的基本概念、网络类型及拓扑结构
-   交换机、路由器、防火墙和无线设备的基本作用
-   常见网络协议的工作原理与基础配置
-   华为网络设备的基本操作和配置方法
-   网络连通性测试、状态查看与基础故障排查
-   根据实验要求完成简单网络的规划、搭建和验证

## 🧪 实验建议

进行实验时，建议保留以下记录：

-   **实验名称：** 本次实验要完成的任务
-   **实验目的：** 需要掌握的知识点或技能
-   **实验拓扑：** 设备连接关系及网络结构
-   **地址规划：** IP 地址、子网掩码、网关等信息
-   **配置过程：** 关键配置命令及说明
-   **验证结果：** `ping`、路由表、邻居状态等检查结果
-   **问题记录：** 实验中遇到的问题及解决方法

## 💻 实验环境

具体实验环境以各实验文档的要求为准。使用真实设备或网络模拟平台时，请注意设备型号、软件版本和命令支持情况可能存在差异。

## 📌 使用说明

1.  克隆或下载本仓库。
2.  阅读培训教材中对应的知识章节。
3.  找到相关实验资料并按步骤完成实验。
4.  将自己的实验结果、配置文件和学习笔记整理归档。
